# رصدنگار (RasadNegar)

سامانه چک‌لیست تولید و ردیابی محصول.

## اجرا
- فایل `Form.html` را با GitHub Pages یا هر وب‌سرور استاتیک سرو کنید.
- آدرس پیشنهادی Pages: بعد از فعال‌سازی از Settings → Pages

## ساختار
- `Form.html` — رابط اصلی
- `assets/` — اسکریپت و استایل
- `auth/` — کاربران و تنظیمات سرویس
- `records/<project>/` — فایل‌های Markdown چک‌لیست
- `forms/` — صفحات پروژه

## توکن سرویس
در پنل مدیریت یک GitHub Personal Access Token با دسترسی `repo` تنظیم شود تا ثبت داده‌ها روی همین مخزن انجام شود.
